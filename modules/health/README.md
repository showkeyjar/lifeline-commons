# 健康模块（basic-health-security）

第 5 个供给插槽，建模**基础健康安全**——一个第一阶、诚实的代理指标，不是一个医疗系统。

## 模型

```
覆盖 = min(1, 自护能力 × (0.7 + 0.3 × 在地可及性))
```

- **自护能力**：主人是否有医护技能 / 启动资本能否买到药与补给 / `asset_scale`（资产规模）能否支撑常备物资。
  - 有「医护」技能 → 0.90
  - 资本 ≥ 2 → 0.65；资本 = 1 → 0.45；资本 = 0 → 0.30
  - 再叠加 `asset_scale` 的小幅提升（更足的资产 → 更稳的常备物资）
- **在地可及性**：离正式医疗的距离代理——乡村/离网 0.5、郊区 0.7、城市 0.9。

## 诚实边界

- 这是**粗粒度代理**，不是医疗建议，也不声称能"解决健康"。
- 健康缺口无法靠"自产"补足，失败时 `fail_mode = "seek-care"`（靠社区互助照护 / 就近卫生站求援）。
- 真实部署应替换为本地卫生站、互助照护网络、保险/公卫数据——只要 conform 到
  `module-interface-v1`，编排层无需改动。

## 多语言

模块本身不产出文案，所有报告字符串由 `lifeline-os/i18n.py` 负责，已支持 zh / en / es。
