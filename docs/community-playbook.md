# 自愿社区启动清单（Community Playbook）

> 把蓝图里"小A申请荒地 → 开荒 → 建系统 → 生存自由"的设想，变成**一群人可复制的部署剧本**。
> 本文是操作手册，不是愿景。适合**自愿**退出市场、且手里已有一定资源（地 / 资本 / 技能 / 组织力）的群体。
>
> **诚实前提**：本项目不服务赤贫无地的城市失业者（最初担心的小A本人）——那部分只能靠政府托底（见 [`docs/floor-options.md`](floor-options.md) §2.5）。本清单服务的是"已有资源、想换一种活法"的人。

---

## 0. 先确认你是不是这批人（门槛自检）

| 你/你们有… | ✅ 适合本清单 | ❌ 不适合 |
|---|---|---|
| 可用土地（自有 / 长租 / 集体承包） | ✅ | 无地 |
| 启动资本或能众筹 | ✅ | 完全无钱 |
| 有人愿意长期参与、接受治理 | ✅ | 只想"买完就走" |
| 接受社区决策、不追求个人独裁 | ✅ | 想要全能机器人替自己干活 |

任一 ❌ 命中，请先争取政府托底（现金底 / 基础服务），本项目不是你的答案。

---

## 1. 组队与共识（项目提供治理模型）

- **规模起点：10–20 户**。理由见 [`docs/floor-options.md`](floor-options.md)——集体冗余能补上单户方案的脆弱性（一次歉收 / 一场病 / 一台设备坏不至于断粮）。
- 通过 [`GOVERNANCE.md`](GOVERNANCE.md)：选举维护者、接纳 5 条范围红线（不交易 / 不圈地 / 不解决意义 / 不造通用 AI / 不替国家再分配）。
- **产出**：一份社区公约（可抄 GOVERNANCE §1–§4）。
- 这一步**完全由社区自己完成**，项目只提供治理模板。

---

## 2. 拿地（成员提供，项目不参与）

- 土地确权 / 承包权是现实最大的一道坎，**非技术问题，本项目不提供地**。
- 清单：确权文件、规划/复垦审批、生态合规（废弃地复垦许可、用水指标等）。
- 地块选择原则：靠近成员、生态可承载、有日照（光伏）与水源（食物/水）。

---

## 3. 部署物理产能（上游硬件，成员采购）

项目**不交付硬件、不交付机器人**。成员按需采购，按 `module-interface-v1` 接入：

| 域 | 参考配置（12 人基线，来自现有模块样例） | 自给率 | 说明 |
|---|---|---|---|
| 能源 | 光伏 10 kWp + 储能 30 kWh | 0.999 | 光伏直供→储能补缺→余电只存不卖 |
| 食物 | 温室/水培 + 库存 150 餐（初 50 / 保 20） | 0.997 | 本地生产→库存补缺→余量入库不卖 |
| 水 | 雨水收集 + 井水（可持续出水量）+ 储水罐 1000 L | 0.991 | 雨水/井水生产→储水罐补缺→余量入库不卖 |
| 住所 / 健康 | 按需 | — | 按同一接口接 `adapters/` |

> 这些是**数据驱动规划的演示值**，不是承诺。真实部署替换 `data/` 后重算。
> **开荒、建房、种养**靠农机 + 人工，不属于本项目范围（见蓝图 `docs/blueprint.md`）。

---

## 4. 接入 Lifeline OS（项目交付核心）

1. `git clone` 仓库，`python lifeline-os/orchestrator.py` 验证闭环跑通。
2. 把你们真实的 `config.json` / `battery.json` / `solar_forecast.csv` / `inventory.json` / `yield_forecast.csv` / `tank.json` / `supply_forecast.csv` 替换 `modules/*/data/` 下的样例。
3. 跑出**你们社区的自给覆盖率**，找出"最弱的那天"针对性补强（调大产能 / 电池 / 库存）。
4. 新增模块：走 [PR 模板](https://github.com/showkeyjar/lifeline-commons/blob/main/.github/PULL_REQUEST_TEMPLATE.md) + GOVERNANCE §3 评审清单。

---

## 5. 持续治理与迭代（社区自己跑）

- **节奏**：季度复审覆盖率、冗余、设备健康度（`status()` 输出）。
- **本地自主权**：实例决策归社区；中央只维护协议与共享经验，不指挥实例怎么活。
- **反捕获**：单一资助方占比 > 50% 触发治理复核（GOVERNANCE §5）。
- **诚实记录**：公开"解决了谁、覆盖多少、没解决什么"——边界也是价值（见阶段 3 运行报告）。

---

## 里程碑自检

- [ ] 社区公约签署（GOVERNANCE）
- [ ] 土地确权完成
- [ ] 能源 / 食物物理产能就位
- [ ] Lifeline OS 跑通且覆盖率达标
- [ ] 首轮治理复审完成
- [ ] 运行报告公开（含边界）

---

## 一句话

本项目交付的是"协调层 + 治理 + 数据驱动规划"，不交付地、不交付机器、不交付全能。**自愿社区 = 成员出地出钱出人 + 项目出协调工具与规则**。二者合起来，才是一个小A们能真正退可守的"生存公地"。
