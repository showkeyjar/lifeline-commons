# 真实社区实例 · 数据来源指南

本指南回答一个问题：**怎么把一份 profile 从"编的"变成"真的"**。
原则是——每一个数字都要能溯源到真实采集。下面按字段给出**可落地的真实来源**。

> 适用对象：想贡献一个真实实例的你 / 某个社群。
> 配套模板见 `instances/_template/`，目录约定见 `instances/README.md`。

---

## 0. 先想清楚：这个实例"真"到什么程度？

三级真实度，按你手头资源选，别勉强：

- **L1 自报真实**：核心 7 键（家庭人数、有地否、资本档、地点、技能、健康、机动性）全来自真实自报；气候/资产能填多少填多少。
- **L2 带环境实测**：在 L1 基础上，`climate` 用真实气象数据、`assets` 用真实设备铭牌。
- **L3 带运行日志**：在 L2 基础上，跑一份 `last-report.md` + 现场 `notes.md`，记录模拟与现实的偏差，形成"验证过的实例"。

**宁可 L1 老实标注未知，也不要 L3 编数据。**

---

## 1. 核心 7 键（必填，且必须真实）

| 字段 | 真实来源 | 备注 |
|---|---|---|
| `household` | 户口本 / 实际共同居住人数 | 用"实际吃饭的人头"，不是户籍数 |
| `has_land` | 是否拥有/长期承包土地 | 含宅基地、承包地、租赁农地 |
| `land_area_m2` | 土地承包合同 / 实地 GPS 测量 | 手机 GPS 轨迹围合即可估 |
| `capital` | 自评 0–3 档（0 赤贫 → 3 宽裕） | 主观但要有依据：存款、可变现资产 |
| `location` | 乡村 / 郊区 / 城市 / 离网 | 决定气候与技能权重 |
| `skills` | 真实掌握的生存技能清单 | 种植、电工、维修、医疗、远程工作… |
| `health` | 良好 / 受限 / 失能 | 影响基础健康域评分 |
| `mobility` | 能否自由移动/撤离 | 灾害场景下关键 |

---

## 2. 气候数据（让自给模拟接地气）

| 字段 | 真实来源 | 怎么取 |
|---|---|---|
| `solar_kwh_per_m2_day` | **NASA POWER**（免费，按经纬度取年均） | power.larc.nasa.gov；或 pvlib 直接拉 |
| `rainfall_mm_year` | **中国气象数据网** data.cma.cn / **NOAA** / **CHIRPS**（非洲等） | 取近 10 年均，别用单年 |
| `avg_temp_c` | 同上气象源 | 年均温 |
| `frost_free_days` | 同上 | 决定种植季长度 |

> 全球通用：NASA POWER、Meteostat、ERA5-Land（前文 cf-steel 项目已用过）。
> 国内：中国气象数据网（需注册，免费）、和风天气历史、各省气象局年鉴。

---

## 3. 资产数据（让能源/水/住所域算得准）

| 字段 | 真实来源 | 怎么取 |
|---|---|---|
| `solar_kw` | 光伏组件 / 逆变器铭牌 | 拍照铭牌即可 |
| `battery_kwh` | 电池铭牌标称容量 | 注意是 kWh 不是 Ah（Ah×V/1000） |
| `wind_kw` | 风机铭牌 | 无则 null |
| `water_storage_l` | 水箱 / 水塔 / 蓄水池容积 | 铭牌或几何估算（πr²h） |
| `well` / `rainwater_harvesting` | 实地确认 | 有井填 true |
| `greenhouse_m2` | 实地测量 | 卷尺 |
| `livestock` | 实际存栏 | 牛/羊/鸡等列表 |

## 4. 进阶：本地化模块参数（可选，但价值高）

默认 `modules/<域>/data/` 是通用参数（如作物单产、设备效率）。真实实例可放一份
`instances/<名字>/override/<域>.json` 覆盖默认值，例如：

- 你这块地的**真实单产**（去年实收 ÷ 面积），比全国均值更准；
- 你这台逆变器的**真实老化效率**；
- 你这口井的**真实出水量**。

> 覆盖机制目前需小改 `provide()` 以读取实例目录；首个真实实例落地时一并接上。

---

## 5. 现场笔记（形成"验证过的实例"）

跑完 `lifeline.py --profile ...` 后，把**模拟 vs 现实**的偏差记到 `notes.md`：

- 模拟说"食物覆盖率 0.9"，但去年实际有 2 个月靠买菜补——为什么？
- 模拟说"能源够"，但冬天实际每天只够 4 小时——哪个参数偏差？

这些偏差是公地最宝贵的资产：它们告诉后来者，**模型在哪漏了真实世界的复杂性**。

---

## 6. 隐私与脱敏

真实实例常含住址、资产等敏感信息。**默认脱敏**：

- 地点写到"县/市"即可，别精确到门牌；
- `author` 可匿名或用化名；
- 涉及他人的数据，取得同意再公开。

贡献时可在 PR 说明"署名/匿名"，公地尊重贡献者意愿。
