# 生存自由报告（Lifeline OS）

> 画像 → 策略推荐 → 供给模拟 → 自由指数，一条闭环。荒地只是策略之一。

## 1. 主人/社区画像

- 是否有地：是
- 启动资本（0-3）：1
- 技能：IT
- 所在地：郊区
- 家庭/社区人数：4
- 健康：良好
- 可迁移：是
- 资产规模系数（本项目推算）：**0.7**(1.0 = 持有与基准社区匹配的产能)

## 2. 推荐策略（按匹配度）

1. **低成本地区迁移（搬去生存成本极低的地区）** — 匹配 90/100 ← 首选
   - ⚠️ 本项目不介入执行，仅提供信息与规划辅助
2. **半自给+基础缓冲（以降开销为主）** — 匹配 65/100
   - ✅ 本项目介入：规划工具（算你能降多少开销/建多少缓冲）
3. **技能变现+小缓冲（手艺/远程工作覆盖开销+建缓冲）** — 匹配 60/100
   - ❌ 本项目不介入，主人自行；可规划缓冲目标
4. **分布式自给（荒地/集体土地自建）** — 匹配 50/100
   - ✅ 本项目介入：协调层 + 治理 + 数据驱动规划（energy/food/water 模块）
5. **城市社区协作（共享空间+分工+半市场）** — 匹配 43/100
   - ✅ 本项目介入：协调层（城市版模块）+ 治理
6. **依赖外部托底（政府/慈善）** — 匹配 0/100
   - ❌ 本项目帮不了——这类人只能靠政府现金底/基础服务

## 4. 生存自由指数

- **分档：中高（靠可携带收入，需持续接单/远程工作）**

## 5. 诚实边界

- 本工具只「分析 + 模拟」，决策权与执行权留在主人与社区手里。
- 若首选是「分布式自给」才需要走拿地/开荒；其他策略不涉及地。
- 模拟是一阶线性规划工具（产能/需求同比缩放），不是承诺；落地前请用你们社区的真实数据替换 `modules/*/data/`。
- 本项目是**自愿社区**的开源协调工具，不替代政府、不交付机器人、不解决人生意义。
