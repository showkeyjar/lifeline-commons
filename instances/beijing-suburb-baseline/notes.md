# 现场笔记 · 北京郊区极限示范

> 本文件记录"模型输出"与"现实"的偏差。它才是这个极限示范最有价值的部分：
> **它告诉后来者，模型在哪漏了真实世界的复杂性——以及我们已经补上了哪些。**

---

## 0. 一句话结论

即便从**近乎零装备**（无光伏、无电池、无井、无储水、无大棚、无牲畜，唯一技能 IT，资本档 1）
的起点，模型给出两条真实可读的路径：
- **脚下这块地的半自给**（semi_self 65 ← 模型首选）：把 4 亩地种起来 + 集雨 + 小规模光伏，是降低开销、提升韧性的在地路径；
- **远程收入杠杆**（skill_buffer 60）：IT 技能被模型正确识别为可远程变现，是 2026 年最现实的缓冲来源。

模型现在的**供给地板诚实地显示 29%**（仅健康 0.52、住所 0.95 有基础分；能源/食物/水 = 0，
因为当前零装备且 4 亩地尚未耕种），而不是早期那套"假设你有全套设备"的虚高 87%。
**希望不在当前分数，而在地板之上的那座桥**（`action-plan.md` 里 17 条任务级指令描述的"建成后日常运营"）。

---

## 1. 仿真现在诚实地反映真实资产（关键修复）

早期版本里，供给仿真硬编码了 `DEFAULT_RESOURCES`（光伏/电池/井/集雨/仓储全在），
导致零装备户也被算出 100% 覆盖。现已修复：仿真只统计画像 `assets` 里**真实拥有/运营**的资源。
本户 `assets` 全为 0/false，于是：

| 域 | 模型仿真覆盖率（修复后） | 当前真实地板 | 说明 |
|---|---|---|---|
| 能源 | 0.000 | 0 | 无光伏/电池；郊区有市电但非自发，离网自给=0 |
| 食物 | 0.000 | 0 | 4 亩地**当前未耕种**，local-farm 仅运营后计入 |
| 水 | 0.000 | 0 | 无井/无集雨/无储水，全靠市政供水 |
| 健康 | 0.486 | 0.486 | 4 人无专职医护，仅基础自救（未假设额外资产，较真实） |
| 住所 | 0.880 | 0.880 | 基于"已建立自有住房"假设；郊区有房基本成立 |

**供给覆盖均值 = 27%**（(0+0+0+0.486+0.880)/5）。这才是对"极限示范"诚实的读数。

> 仍存的诚实口径：食物=0 是因为**土地尚未耕种**，而非"不能种"。一旦种起来（建大棚或给 assets 加
> `"farm": true`），local-farm 即计入，食物覆盖立刻跳到可建成上限。这正是"桥"的第一级台阶。

## 2. 模型语义偏差（IT 已修复；mobility 仍需注意）

### 2.1 技能词典（已修复）
此前 `IT` 不被识别为可变现技能，`skill_buffer` 直接 0 分。现已把 `IT / 远程 / Remote` 纳入
可变现词典——本户 `skill_buffer` 由 0 → 60，`relocate` 由 70 → 90（IT 的远程变现潜力被正确计入）。
**原则是：不篡改你的自报数据（技能仍是 IT），而是让模型学会认识现代技能。**

### 2.2 `mobility` 语义双重（已修复 ✅）
早期 `mobility=true` 既表示"能自由撤离"又被当作"想搬家"的触发器，把 **"低成本地区迁移"误推为首选（90 分）**。
现已拆分为两个独立维度：
- `mobility` = **撤离能力**（灾害韧性）：只贡献自由指数的定性韧性（+10），**不再触发**迁移策略；
- `relocation_willingness` = **迁移意愿**：仅当显式为 `true` 才触发 relocate（缺省 `false`）。

本户设 `relocation_willingness=false`（本意是在自家 4 亩地上建自给，不搬家），于是 relocate 正确归零，
**semi_self（65）自然成为模型首选**——这正是本示范想要的诚实结果。
新增测试 `test_mobility_is_evacuation_not_relocation` 与 `test_relocation_willingness_triggers_relocate`
永久守护该拆分（防止有人把"有撤离韧性"误读回"该搬家"）。

## 3. 重新审视"生存自由指数"

模型现在的首选是 `semi_self`（65），自由指数由模型**直接算出 54.2/100（中·半自由，需持续外部收入补足缺口）**：
- 构成：`供给覆盖均值 29% × 0.5` + `策略匹配 65 × 0.3` + `定性韧性 100 × 0.2`
  = 14.5 + 19.5 + 20 = **54.2**。
- 定性韧性 100 的来源：基础 50 + 健康良好(+25) + 小户≤4人(+15) + 有地/郊区(+10) + 撤离能力(+10)。
- 这与"在自家地上建自给"的直觉一致：分数不高（能源/食物/水当前为 0），但**真实且可读**。

> 早先那版"relocate 90 → 指数 77.3"是误读产物（mobility 被当迁移意愿）。纠正语义后，
> 该户若真要搬家需显式 `relocation_willingness=true`，否则模型不再替你做"该搬家"的假设。
> IT 远程收入杠杆仍在（skill_buffer 60），它负责攒建缓冲的资本；4 亩地负责降低对市场的依赖——两手都该抓。

## 4. 结合北京真实气候：第一年低成本优先序

把 NASA POWER 真实气候（年均辐照 3.95 kWh/m²/天、年降雨 533 mm、无霜期 ~190 天）
与零装备现实结合，建议启动顺序（不要求一次到位）：

1. **先把 4 亩地种起来（几乎零设备投入）**——把食物地板从 0 抬起，也是 local-farm 计入产能的前提。
2. **集雨 + 小储水（低成本）**——年降雨 533 mm × 4 亩集雨面 ≈ 可观蓄水量；先建几吨储水。
3. **小规模光伏 + 电池（资本档 1 可起步）**——北京辐照 3.95，足以支撑关键负载离网。
4. **健康缓冲**——补基础急救 + 远程问诊（IT 技能正好用上）。

`action-plan.md` 的 17 条指令 = 上述资产**建成之后**机器人每天/按需该干什么。
它们现在大多"还无法执行"（前置条件依赖尚不存在的资产），但**指明了建成的样子**——这正是希望。
